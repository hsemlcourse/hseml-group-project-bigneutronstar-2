## Описание задачи

**Задача:** Трехклассовая классификация направления движения цены фьючерса на золото (с отсечением "флэтового" шума).

**Датасет:** Часовые данные по фьючерсам на золото (GC), февраль 2024 - февраль 2026. Поддерживается автопарсинг свежих данных.

**Целевая метрика:** Macro F1-score и OVR ROC-AUC. Основным бизнес-показателем выступает Hit Rate (доля прибыльных предсказаний в бэктесте).

Проект решает задачу прогнозирования направления движения цены фьючерса на золото. На основе исторических ценовых, объемных и технических признаков модель определяет, будет ли сильный рост (Up), сильное падение (Down) или цена останется в рамках шумового канала (Flat) на горизонте N часов.

## Данные

### Основной датасет: `gold_data_1h_cleaned.csv`

| Характеристика | Значение |
|---|---|
| Гранулярность | 1 час |
| Период | 2024-02-11 - 2026-02-06 |
| Кол-во строк | 11 423 |
| Столбцы | DateTime, Date, Time, Year, Month, Day, Hour, Open, High, Low, Close, Volume, Price_Change, Price_Change_Percent |
| Пропуски | 1 (Price_Change первой строки); OHLCV без пропусков |

Выбран часовой датасет, потому что гранулярность подходит для краткосрочного прогноза (h=24 часов), данных больше для ML, и OHLCV без пропусков.

### Как подключить данные
Вы можете использовать оригинальный `gold_data_1h_cleaned.csv` или запустить автоматический сбор с Yahoo Finance (сохранится в `data/gold_data_1h_cleaned.csv` и будет использоваться скриптами):
```bash
make parser
```


## Постановка ML-задачи

| Параметр | Значение |
|---|---|
| **Тип задачи** | Трехклассовая классификация (0: Down, 1: Flat, 2: Up) |
| **Target порог** | Отсечение плоского рынка `threshold = 0.002` (0.2% движения) |
| **Горизонт** | h=24 часа |
| **Валидация** | Walk-forward CV (3 фолда) для подбора + финальный holdout (80/20) |
| **Новые признаки** | Momentum, ATR-14, Z-scores цены и объема, соотношение теней свечи |

Всего используется **39+ признаков**. Все признаки используют **только прошлую информацию** (через лаги `shift`). Leakage отсутствует.

## Результаты

Переход от бинарной к трехклассовой (3-class) классификации с отсеканием шума `threshold = 0.002` на горизонте `h=24` значительно улучшил понимание рыночных движений.

### Финальные Tuned-модели (на отложенной выборке)

| Модель | Accuracy | Macro F1 | OVR ROC-AUC | Backtest: Подтвержденных сделок | Hit Rate (Прибыльные) | Ср. доходность на сделку |
|---|---|---|---|---|---|---|
| LogisticRegression_tuned | 0.4525 | 0.3204 | 0.5439 | 1660 | 50.30% | 0.1621% |
| RandomForest_tuned | 0.5425 | 0.2395 | 0.5377 | 1512 | 61.24% | 0.3699% |
| GradientBoosting_tuned | 0.4384 | 0.3106 | 0.5333 | 1855 | 50.84% | 0.0180% |
| CatBoost_tuned | 0.4808 | 0.3207 | 0.5246 | 1438 | 56.12% | 0.1700% |

**Интерпретация:**
Сигнал на высоколиквидном рынке остается слабым (ROC-AUC ~ 0.52-0.54). Однако фильтрация вероятностей (когда сделка открывается только при достаточной уверенности классификатора) позволила Random Forest достичь Hit Rate > 60% и стабильно положительного матожидания сделки (~0.37% грязной доходности на трейд).
