## Описание задачи

**Задача:** Бинарная классификация направления движения цены фьючерса на золото

**Датасет:** Часовые данные по фьючерсам на золото (GC), февраль 2024 - февраль 2026

**Целевая метрика:** ROC-AUC (основная), Accuracy, F1-score (дополнительные)

Проект решает задачу прогнозирования направления движения цены фьючерса на золото. На основе исторических ценовых, объемных и технических признаков модель определяет, вырастет или упадет цена на горизонте N часов.

## Данные

### Основной датасет: `gold_data_1h_cleaned.csv`

| Характеристика | Значение |
|---|---|
| Гранулярность | 1 час |
| Период | 2024-02-11 - 2026-02-06 |
| Кол-во строк | 11 423 |
| Столбцы | DateTime, Date, Time, Year, Month, Day, Hour, Open, High, Low, Close, Volume, Price_Change, Price_Change_Percent |
| Пропуски | 1 (Price_Change первой строки); OHLCV без пропусков |
| Дубликаты | Нет |

Выбран часовой датасет, потому что:
- Больше наблюдений - лучше для ML
- Гранулярность подходит для задачи краткосрочного прогноза
- OHLCV-данные чистые, без пропусков

### Как подключить данные
Файлы должны лежать в `data/raw/`. Они добавлены в `.gitignore`, поэтому если репозиторий клонирован без данных, нужно вручную разместить CSV-файлы в `data/raw/`.


## Постановка ML-задачи

| Параметр | Значение |
|---|---|
| **Тип задачи** | Бинарная классификация |
| **Target** | 1 - цена через N часов выше текущей; 0 - иначе |
| **Горизонты** | h=1, h=4, h=24 (часы) |
| **Валидация** | Holdout (80/20 по времени) + walk-forward CV (5 фолдов) |
| **Train период** | Февраль 2024 - Сентябрь 2025 |
| **Test период** | Сентябрь 2025 - Февраль 2026 |
| **Баланс классов** | ~52% / 48% (незначительный дисбаланс) |

### Признаки (39 штук)

| Группа | Признаки |
|---|---|
| Доходности | return_1, return_2, return_4, return_8, return_24 |
| Ценовые лаги | close_lag_{1,2,3,4,8}_ratio |
| Волатильность | rolling_std_{6,12,24,48} |
| Отклонение от MA | dev_from_ma_{6,12,24,48} |
| High-Low range | hl_range, hl_range_rolling_6 |
| Объем | volume_ratio_6, volume_ratio_24 |
| Свечные паттерны | upper_shadow, lower_shadow |
| RSI | rsi_14, rsi_6 |
| MACD | macd, macd_signal, macd_hist |
| Bollinger Bands | bb_upper/lower/width/position_{12,24} |
| Календарь | hour, dayofweek |

Все признаки используют **только прошлую информацию**. Leakage отсутствует.

## Модели

| # | Модель | Описание |

### Интерпретация

Все модели показывают ROC-AUC в районе 0.50-0.53, что означает слабый предсказательный сигнал. Это ожидаемый результат для краткосрочного прогнозирования цен на финансовых рынках - предсказуемые паттерны арбитражируются участниками рынка.

Наиболее информативны: волатильность (rolling_std), MACD-компоненты, ширина полос Боллинджера и отклонения от скользящих средних. Горизонт h=24 дает более стабильный сигнал, чем h=1 или h=4.


## Выводы

### Что сделано
- Постановка задачи бинарной классификации
- Предобработка и очистка данных
- 39 признаков: базовые + технические индикаторы (RSI, MACD, Bollinger Bands)
- Корректный временной split, без leakage
- 3 модели: Logistic Regression (baseline), Random Forest, Gradient Boosting
- Walk-forward cross-validation (5 фолдов)
- Тюнинг гиперпараметров по сетке (walk-forward CV)

- Не тестировались нейросетевые архитектуры
