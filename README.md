## Описание задачи

**Задача:** Бинарная классификация направления движения цены фьючерса на золото

**Датасет:** Часовые данные по фьючерсам на золото (GC), февраль 2024 — февраль 2026

**Целевая метрика:** ROC-AUC (основная), Accuracy, F1-score (дополнительные)

Проект решает задачу прогнозирования **краткосрочного направления** движения цены фьючерса на золото. На основе исторических ценовых, объёмных и технических признаков модель определяет, вырастет или упадёт цена на горизонте 1 час.

## Данные

### Основной датасет: `gold_data_1h_cleaned.csv`

| Характеристика | Значение |
|---|---|
| Гранулярность | 1 час |
| Период | 2024-02-11 — 2026-02-06 |
| Кол-во строк | 11 423 |
| Столбцы | DateTime, Date, Time, Year, Month, Day, Hour, Open, High, Low, Close, Volume, Price_Change, Price_Change_Percent |
| Пропуски | 1 (Price_Change первой строки); OHLCV без пропусков |
| Дубликаты | Нет |

Выбран **часовой датасет**, потому что:
- Больше наблюдений → лучше для ML
- Гранулярность подходит для задачи «краткосрочного прогноза»
- OHLCV-данные чистые, без пропусков

### Альтернативный датасет: `gold_data_daily_comprehensive_cleaned.csv`
Дневные данные (6383 строк, 2000–2026) с предрассчитанными скользящими средними. Не используется в CP1 из-за меньшего числа наблюдений, но может быть полезен для долгосрочного прогноза.

### Как подключить данные
Файлы должны лежать в `data/raw/`. Они уже добавлены в `.gitignore`, поэтому если репозиторий клонирован без данных, нужно вручную разместить CSV-файлы в `data/raw/`.


## Постановка ML-задачи

| Параметр | Значение |
|---|---|
| **Тип задачи** | Бинарная классификация |
| **Target** | 1 — цена через 1 час выше текущей; 0 — иначе |
| **Горизонт** | 1 час (h = 1) |
| **Валидация** | Temporальный holdout: 80% train / 20% test, строго по времени |
| **Train период** | Февраль 2024 — Сентябрь 2025 |
| **Test период** | Сентябрь 2025 — Февраль 2026 |
| **Баланс классов** | ~52% / 48% (незначительный дисбаланс) |

**Горизонт h=1 час** выбран как минимально возможный для часовых данных: наиболее практически интересный краткосрочный прогноз.

### Признаки (26 штук)

| Группа | Признаки |
|---|---|
| Доходности | return_1, return_2, return_4, return_8, return_24 |
| Ценовые лаги (ratio) | close_lag_{1,2,3,4,8}_ratio |
| Волатильность | rolling_std_{6,12,24,48} |
| Отклонение от MA | dev_from_ma_{6,12,24,48} |
| High-Low range | hl_range, hl_range_rolling_6 |
| Объём | volume_ratio_6, volume_ratio_24 |
| Свечные паттерны | upper_shadow, lower_shadow |
| Календарь | hour, dayofweek |

Все признаки используют **только прошлую информацию** (лаги, rolling по историческим данным). Leakage отсутствует.

### Интерпретация

Все модели показывают ROC-AUC в районе 0.50–0.51, что означает **очень слабый предсказательный сигнал**. Это ожидаемый результат для краткосрочного прогнозирования цен на финансовых рынках:

- Рынок фьючерсов на золото — высоковолатильный и высоколиквидный, предсказуемые паттерны арбитражируются участниками рынка
- Часовой горизонт — особенно сложен, так как на этом таймфрейме доминирует шум
- Наиболее информативные признаки — волатильность (rolling_std), отклонение от скользящих средних и объёмные аномалии

**Дисбаланс классов** минимален (~52/48), специальная коррекция не требуется.
